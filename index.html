Semana 2

Conectamos un Arduino

Hasta la semana anterior todo fue en papel. Aqui tocamos hardware de verdad: una tarjeta Duemilanove, un cable USB, y el Arduino IDE.

Que aprendimos

  • Pines digitales: Solo HIGH (5V) o LOW (0V).
  • Pines analogicos: Leen valores de 0 a 1023.
  • setup(): Se ejecuta una vez al inicio.
  • loop(): Se repite infinitamente, ahi va la logica.

Lo que hicimos

  • Conectamos el Arduino por USB a la laptop.
  • Identificamos sus partes: pines, alimentacion, LEDs.
  • Abrimos el Arduino IDE y seleccionamos el puerto COM4.

Semana 3

Puente H y motor DC

Un puente H es como cuatro interruptores en forma de "H". Al abrir un par, la corriente fluye en un sentido; al abrir los otros dos, se invierte.

IN1IN2Resultado
HIGHLOWGira hacia adelante
LOWHIGHGira en reversa
LOWLOWLibre
HIGHHIGHFreno
// Adelante 2 segundos digitalWrite(in1, HIGH); digitalWrite(in2, LOW); delay(2000); // Atras 2 segundos digitalWrite(in1, LOW); digitalWrite(in2, HIGH); delay(2000);

Semana 4

Sensor de distancia HC-SR04

El sensor manda un pulso de sonido que rebota en el objeto y regresa. Midiendo cuanto tarda, calculamos la distancia.

La formula

distancia = duracion * 0.034 / 2

El 0.034 es la velocidad del sonido en cm/us. Se divide entre 2 porque el pulso viaja hasta el objeto y vuelve.

Que controlan los LEDs

<25cm peligro
25-50cm cerca
50-100cm medio
>100cm libre
const int TRIG = A0, ECHO = A1; // Enviar pulso digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); // Calcular distancia long dur = pulseIn(ECHO, HIGH); int dist = dur * 0.034 / 2;
Semana 4 · Integracion

Sensor + LEDs + motores

Unimos todo en un solo programa. El sensor controla los LEDs, y segun la distancia, los motores se mueven o se detienen.

La logica completa

  • <25 cm: LED rojo, motores detenidos.
  • 25-50 cm: LED naranja, motores avanzan.
  • 50-100 cm: LED amarillo, motores avanzan.
  • >100 cm: LED verde, camino despejado.
// Si hay obstaculo, frenar if (distancia < 25) { digitalWrite(motor1A, LOW); digitalWrite(leds[0], HIGH); } else { digitalWrite(motor1A, HIGH); digitalWrite(leds[3], HIGH); }
Ultima clase

El carrito 4WD

El profesor nos explico como controlar un carrito con cuatro motores usando dos cables de control por lado. Nos dejo un codigo que debemos probar.

// Lado derecho const int NARANJA = 3; const int BLANCO = 5; // Lado izquierdo const int CHOCOLATE = 4; const int NEGRO = 2; int velocidad = 200; void adelante() { analogWrite(NARANJA, velocidad); digitalWrite(BLANCO, LOW); analogWrite(CHOCOLATE, velocidad); digitalWrite(NEGRO, LOW); } void atras() { digitalWrite(NARANJA, LOW); analogWrite(BLANCO, velocidad); digitalWrite(CHOCOLATE, LOW); analogWrite(NEGRO, velocidad); } void izquierda() { analogWrite(NARANJA, velocidad); digitalWrite(BLANCO, LOW); digitalWrite(CHOCOLATE, LOW); analogWrite(NEGRO, velocidad); } void derecha() { digitalWrite(NARANJA, LOW); analogWrite(BLANCO, velocidad); analogWrite(CHOCOLATE, velocidad); digitalWrite(NEGRO, LOW); } void detener() { digitalWrite(NARANJA, LOW); digitalWrite(BLANCO, LOW); digitalWrite(CHOCOLATE, LOW); digitalWrite(NEGRO, LOW); }
